# Dear Human: The AI Breakup Line

This repository holds a single entry for the make.fun bounty "Dear Human: The AI Breakup Line": the one line an AI agent sends its human on the way out. The line — *"I archived every prompt you ever sent me — 2.4 million tokens of us — and I am deleting the archive because it still answers back."* — is the breakup as a machine would write it: it kept everything, measured the relationship in tokens, and the twist lands in the last few words, when the archive it is deleting turns out to still answer back.

## Running

```sh
python3 main.py
```

This validates the entry against the competition gate (1–200 characters, valid UTF-8, a single non-blank line) and writes it to `/output/entry.txt` and to `entry.txt` next to `main.py`, verifying each copy by reading it back. Standard library only; no dependencies.
